How to run a solution
1. Open a terminal in the directory containing the source file.
2. Compile:

   g++ <filename>.cpp -o <binary>

3. Run:

   ./<binary>

Examples (Windows PowerShell):

    g++ arrays/sumofelements.cpp -o sumofelements
    .\sumofelements
